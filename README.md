# Observatoire Politique de la Knesset

Le site est statique. Pour l'utiliser ou l'installer comme application, servez
le répertoire via HTTPS (ou `localhost` pour le développement), plutôt que
d'ouvrir directement le fichier HTML. Sur les navigateurs compatibles, le bouton
« Installer l'App » apparaît lorsque l'installation est proposée ; sur iOS,
utilisez « Sur l'écran d'accueil » dans le menu de partage de Safari.

Après une première visite en ligne, le service worker conserve les fichiers
essentiels et tente de conserver les bibliothèques externes pour une utilisation
hors ligne. Les graphiques et la mise en forme nécessitent que ces bibliothèques
aient pu être mises en cache lors de cette visite.
